# Conference talk proposal

**Title:** Sync without servers: building a local-first app in a weekend

**Abstract:** Most apps assume a server is the source of truth. What if every device is? Using a small habit tracker as the running example, this talk walks through append-only logs, CRDT merges and peer discovery, and the bugs you only find when two phones disagree about what day it is.

**Length:** 30 minutes
