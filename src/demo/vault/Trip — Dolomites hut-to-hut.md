# Trip — Dolomites hut-to-hut

An idea for late summer: Alta Via 1, six days, sleeping in rifugi.

## Route sketch

1. Lago di Braies → Rifugio Biella
2. → Rifugio Fanes
3. → Rifugio Lagazuoi (sunset from the terrace!)
4. → Rifugio Nuvolau
5. → Rifugio Coldai
6. → down to Agordo, bus back
