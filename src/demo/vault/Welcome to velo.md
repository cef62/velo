# Welcome to velo

This is a **live demo** of velo running in your browser. Everything you see is a made-up notes folder belonging to Sam, a software developer. Nothing you type is saved — reload the page to start over.

Things to try:

- Type in the search field at the top: the list filters as you type. Try `lisbon` or `#recipes`.
- Press ⌘P (Ctrl+P) for the command palette.
- Open the **Filters** panel to combine tags, or show only notes with no links.
- Open the side panel to see what links here: try it on [[Project Lantern]].
- Switch to **Tasks** or **Timeline** with the tabs above the list.
- One note is locked. Its passphrase is `demo`.

Notes link to each other with double brackets, like [[Reading list]] or [[Weekly plan]]. A link to a note that does not exist yet, like [[Gear list]], creates it when you follow it.
