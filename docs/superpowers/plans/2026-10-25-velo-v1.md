# Velo v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A cross-platform, keyboard-driven notes app (nvALT successor) over a flat folder of Markdown files, with instant search-or-create, live file watching, Markdown preview with `[[wiki links]]`, global hotkey and per-note encryption.

**Architecture:** Tauri 2 app at the repo root. All note logic lives in a Rust `Vault` (plain struct, no Tauri types) so it is unit-testable and reusable later by an MCP server; `commands.rs` is a thin Tauri wrapper over it. Files are the source of truth; SQLite (FTS5 trigram) is a rebuildable cache in the app data dir. UI is plain TypeScript + Vite + CodeMirror 6 + markdown-it.

**Tech Stack:** Tauri 2, Rust (edition 2024), rusqlite (`bundled`), notify + notify-debouncer-full, age, keyring, chrono, unicode-normalization, anyhow; TypeScript, Vite, CodeMirror 6, markdown-it, vitest. Add crates/packages at latest stable with `cargo add` / `pnpm add`.

**Spec:** `docs/superpowers/specs/2026-10-25-velo-design.md`. Spike reference (throwaway, gitignored): `spikes/tauri/` and `docs/spikes/2026-10-25-tauri-results.md`.

## Global Constraints

- Clean-room: never copy code from nvALT/Notational Velocity. Never use the names "nvALT" or "Notational Velocity" or their icons.
- License MIT. App name `velo`, bundle identifier `dev.velo.app`.
- Flat notes folder: no recursive scan; dotfiles and subfolders ignored. Note files: `*.md`, `*.txt`, `*.md.age`. New notes are `Title.md`.
- Files are source of truth; the SQLite index lives in the Tauri app data dir, never inside the notes folder, and deleting it loses nothing.
- Search target: results update per keystroke, backend <50 ms p95 at 10k notes (release build).
- Plaintext of encrypted notes is never written to disk or to SQLite.
- Write files atomically (temp file in same dir + rename).
- Default global hotkey `CommandOrControl+Shift+Space`.
- Unsigned release builds only (no signing/notarization/auto-update in v1).
- Benchmark only release builds.

## Decisions this plan adds (planner's calls, flag to owner)

- **Encryption mechanism:** age *passphrase* (scrypt) costs ~0.5–1 s per file, too slow for autosave and decrypting all locked notes at launch. Instead: one age X25519 identity; notes are encrypted to it (fast). The identity is stored in the OS keychain (auto-unlock) and also saved as `<notes>/.velo/identity.age`, encrypted with the user's one passphrase, so another machine can unlock with that passphrase. Files stay standard age (`age -d -i key`). Preserves the spec decision: one passphrase, keychain, auto-unlock.
- **Short queries (<3 chars):** match titles only (trigram FTS cannot match <3 chars; avoids the 26 ms full scan seen in the spike).
- **Multi-word queries:** every whitespace-separated term must match. Title group = all terms in title; body group = all terms in title or body.
- **Reconcile by mtime + size** (no stored content hash). Content hashes (std `DefaultHasher`, in-process only) are used for conflict detection and self-write suppression.
- **No tags table:** tags are `#tag` text in the body, found by normal body search (spec goal "tags searchable" met).
- **Deferred:** OpenMeta xattr tag reading, note deletion from the UI (delete via Finder/Explorer; watcher handles it), `[[Title|alias]]`.

## Review Focus

1. Note content containing raw HTML/`<script>` (folder synced from elsewhere) → shown as text, never executed. Pinned in Task 10 (`renders_html_as_text`) + CSP in Task 1.
2. Titles with illegal filename chars, case-only collisions, or >200 bytes → sanitized/truncated; duplicates open the existing note. Pinned in Task 2 and Task 7.
3. Non-UTF-8 or binary file named `.txt`/`.md` in the folder → indexed lossily, app keeps working, file not rewritten unless the user edits it. Pinned in Task 7 (`reconcile_tolerates_non_utf8`).
4. Queries containing `"` `%` `_` `*` `-` `NEAR` `(` → matched literally, never an SQL/FTS error. Pinned in Task 4 (`search_metacharacters_literal`).
5. Open note deleted or renamed externally (sync tool) while editing → no data loss: next save recreates the file; a watcher "removed" event does not clear the editor. Pinned in Task 7 (`save_after_external_delete_recreates`) and Task 9 manual check.

### Task 4: SQLite index (`index.rs`)

**Files:** Create `src-tauri/src/index.rs`, `src-tauri/tests/perf.rs`; `cargo add rusqlite --features bundled`, `cargo add anyhow`, `cargo add --dev tempfile`

**Interfaces:**
- Consumes: `text::fold`, `text::extract_links`, `names::NoteFile`.
- Produces:
  - `#[derive(Serialize, Clone, Debug)] pub struct Hit { pub path: String, pub title: String, pub snippet: String, pub mtime: i64, pub encrypted: bool }`
  - `pub struct Meta { pub mtime: i64 /* ms */, pub size: u64 }`
  - `pub struct Index` with:
    - `pub fn open(db_path: &Path) -> anyhow::Result<Index>` (creates schema; `:memory:` allowed for tests)
    - `pub fn known(&self) -> anyhow::Result<HashMap<String, Meta>>` — path → stored meta, for reconcile
    - `pub fn upsert(&mut self, path: &str, nf: &NoteFile, meta: &Meta, body: Option<&str>) -> anyhow::Result<()>` — `None` body for encrypted notes (title only, no FTS row, no links)
    - `pub fn remove(&mut self, path: &str) -> anyhow::Result<()>`
    - `pub fn search(&self, query: &str, limit: usize, unlocked: &HashMap<String, String>) -> anyhow::Result<Vec<Hit>>`
    - `pub fn find_title(&self, title: &str) -> anyhow::Result<Option<String>>` — path of note whose `fold(title)` matches
    - `pub fn backlinks(&self, title: &str) -> anyhow::Result<Vec<String>>` — paths linking to `title` (folded)

Schema:
```sql
CREATE TABLE IF NOT EXISTS notes(path TEXT PRIMARY KEY, title TEXT NOT NULL, title_folded TEXT NOT NULL,
  mtime INTEGER NOT NULL, size INTEGER NOT NULL, encrypted INTEGER NOT NULL, preview TEXT NOT NULL);
CREATE VIRTUAL TABLE IF NOT EXISTS notes_fts USING fts5(path UNINDEXED, body, tokenize="trigram remove_diacritics 1");
CREATE TABLE IF NOT EXISTS links(src TEXT NOT NULL, dst_folded TEXT NOT NULL);
CREATE INDEX IF NOT EXISTS links_dst ON links(dst_folded);
```
`preview` = first 120 chars of body after dropping a leading `# <title>` line (empty for encrypted).

Search algorithm (the part the tests don't fully determine):
- `terms` = `fold(query)` split on whitespace. Empty → all notes by `mtime DESC`, `limit`.
- Title group: notes where every term is a substring of `title_folded` (`LIKE '%' || ? || '%' ESCAPE '\'`, escape `\ % _`), `mtime DESC`; snippet = `preview`.
- Body group (only terms with ≥3 chars; skip group if none): FTS `MATCH` of each long term as a quoted phrase (`"` doubled) joined by spaces (implicit AND), plus every short term must be in `title_folded`; exclude title-group paths; `mtime DESC`; snippet = `snippet(notes_fts, 1, '', '', '…', 12)`.
- Unlocked encrypted notes: for entries in `unlocked` (path → plaintext) not already hit, add to the body group if every term is in `fold(title)` or `fold(plaintext)`; snippet = first 120 chars.
- Result = title group ++ body group, truncated to `limit`.

    - `pub fn open_note(&mut self, path: &str, identity: Option<&str>) -> anyhow::Result<NoteDoc>` — encrypted + no identity → `anyhow!("locked")`
    - `pub fn open_or_create(&mut self, title: &str, identity: Option<&str>) -> anyhow::Result<NoteDoc>` — `index.find_title` hit → open it; else create empty `note_path(dir, title, false)`, index it, return doc
    - `pub fn save_note(&mut self, path: &str, text: &str, base_hash: &str, identity: Option<&str>) -> anyhow::Result<SaveResult>` — encrypts when path ends `.age` (no identity → `"locked"`); on `Saved` re-index (encrypted: `upsert(.., None)` + update `unlocked`); on `Conflict` index the conflict file
    - `pub fn rename_note(&mut self, path: &str, new_title: &str, rewrite_links: bool) -> anyhow::Result<RenameResult>` — store rename, re-index; if `rewrite_links`, for each `index.backlinks(old_title)` (plain notes only) apply `text::rewrite_links` and `write_atomic`
    - `pub fn backlink_count(&self, title: &str) -> anyhow::Result<usize>`
    - `pub fn lock_note(&mut self, path: &str, identity: &str) -> anyhow::Result<String>` — write `.md.age`, delete plain file, re-index, keep plaintext in `unlocked`; returns new path
    - `pub fn unlock_note(&mut self, path: &str, identity: &str) -> anyhow::Result<String>` — inverse; returns new path
    - `pub fn lock_all(&mut self)` — clears `unlocked`
    - `pub fn apply_fs_changes(&mut self, paths: &[PathBuf], identity: Option<&str>) -> Vec<String>` — for each note file: skip if `store.take_self_write`; existing → re-index (decrypt into `unlocked` if possible); missing → `index.remove` + drop from `unlocked`. Returns changed paths (strings) for the UI.
- DB path chosen by caller (Task 8): `<app_data_dir>/index-<hash(dir path)>.sqlite`.
